# claude-agents

Live agent files from my Claude Code org, published alongside articles on [hcd.ai](https://hcd.ai) that dissect them. Each file is the specimen the article walks you through, not a sanitised summary.

## What's here

```
agents/
  accessibility.md   # v2.1, last updated 2026-05-18 · WCAG 2.2 AA audits, ARIA patterns, remediation roadmaps
```

More agent files land here as further articles dissect them. Each entry is pinned to its current version and last-updated date so you can see what state the file was in when its article shipped.

## Why

Most writing about AI agents describes them abstractly. These files are the actual ones running in my system — frontmatter, prompt body, behaviour rules, output format, usage tracking. Fork what's useful. Bend it to whatever discipline you're codifying.
